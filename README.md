Тема дипломной работы - Веб-сервис интеллектуального анализа вакансий и построения плана для подготовки к собеседованию (на примере вакансий в IT-отрасли)

Для реализации интерфейса был выбран язык программирования JavaScript с использованием библиотек React и Bootstrap, для программно-аппаратной части – фреймворк Django, Rest API и СУБД SQL Lite, для сбора данных использовался Scrapy
